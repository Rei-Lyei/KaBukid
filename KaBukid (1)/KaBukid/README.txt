KaBukid Prototype

1. Extract the entire ZIP, keeping the assets folder with the HTML files.
2. Open index.html (or login.html) in your browser. VS Code Live Server also works.
3. Enter any username/email and password, choose Buyer or Farmer, then log in.
   Registration also accepts any input and opens the storefront directly.
4. Click Messages, Chat with a farmer, or Message farmer on a product card.
5. Pick a conversation, type a message and click Send. Sample replies are simulated.
6. Use Buyer view / Farmer view to demonstrate both sides of a conversation.
   Turn off Simulate replies to manually send messages from both sides.
7. Log out to return to the login page.

No database, backend or real authentication is used. Passwords are never saved.
The demo profile lasts for the browser tab session. Conversations, theme and cart
use browser storage when available. Chats are not transmitted to real people or
synchronized between devices. Farmer identities are fictional samples.
Reset sample chats restores the example conversations.

Existing catalog, product images, search, filters, Sako and demo checkout retained.
